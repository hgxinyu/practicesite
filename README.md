# Practice Site

A standalone Algebra 1 practice website.

## Files

- `index.html`: the complete website, including styles and question-generation logic.
- `.gitignore`: excludes local operating-system files, dependencies, and environment files.

## Preview

Open `index.html` in a modern browser. No installation or build step is required.

## Future Netlify connection

Connect the `hgxinyu/practicesite` GitHub repository. Leave the build command empty and use `.` as the publish directory. Deploy only this repository, not the parent Sophia folder.

## Scope

This repository contains the practice website only. Family records and the Sophia knowledge base are stored outside this repository.

The initial `index.html` was copied from `../practice/algebra-1.html`. It is an independent copy; future website edits should be made here.
